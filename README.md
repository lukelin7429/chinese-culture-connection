# Chinese Culture Connection — Promotional Page

A single-page promotional / fundraising web poster for the **Chinese Culture Connection (華夏文化協會)**, a Malden, Massachusetts 501(c)(3) nonprofit that has built bridges between American and Chinese communities across Greater Boston since 1985.

- **Live page:** https://lukelin7429.github.io/chinese-culture-connection/
- **Organization:** https://chinesecultureconnection.org
- Built as a standalone, dependency-free `index.html` (American English). Imagery is the organization's own event artwork.

> This is an independent, third-party promotional page created to help publicize the organization's work and mission.
